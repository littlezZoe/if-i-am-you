# 如果我是它 · 深圳湾黑脸琵鹭互动科普

深圳大铲湾黑脸琵鹭科普交互学习页面。以「如果我是它」的视角，跟随一只黑脸琵鹭完成迁徙、觅食、栖息的旅程，在互动叙事中了解湿地生态与候鸟保护知识。

## 特点

- 🪶 互动叙事：以第一人称体验黑脸琵鹭的迁徙之旅
- 🎨 线稿风格：纯 SVG 手绘线稿，不依赖任何外部资源
- 📦 单文件：所有样式、脚本、插画内联在一个 HTML 文件里，双击即用

## 使用

直接用浏览器打开 `spoonbill-story.html` 即可，无需安装任何东西。

## 技术

纯 HTML / CSS / JavaScript 单文件实现，无框架、无构建、无外部依赖。
